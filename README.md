Contains the code to support Goble et al analysis of muLECs. 

It contains two branches-- one for imgaging (Figure 1) and one for post-seizure analysis (Figure 6). 

Figure 1: connectivity.ijm is an ImageJ macro for analysis of muLEC connected parts
          inclusion bodies latest.ijm is an ImageJ macro for analysis of muLEC microsomes/inclusions

Figure 6:   BLEC seizure study.m is a Matlab file containing the command lines to analyze behaviour after a seizure. It works on the three .mat files (250422_04, 250423_06, and 250420). These files are generated by sleep_analysis2020.m, a Matlab code for analysis of Viewpoint Lifesciences Zebrabox tracking data. sleep_analysis_2020.m is available at: https://github.com/JRihel/Sleep-Analysis

Figure 6: BLEC-salt study.m is a Matlab file containing the command lines to analyse behavioura during and after a salt stress. It works on three .mat files (260526_A6.mat, 260610_08.mat, 260617_08.mat). These files are generated by sleep_analysis2020.m
