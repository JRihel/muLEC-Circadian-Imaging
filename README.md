Contains the code to support Goble et al analysis of muLECs. 

It contains two branches-- one for imgaging (Figure 1) and one for post-seizure analysis (Figure 5). 

Connectivity.ijm is a macro in ImageJ that was used to analyze features of the muLEC's interconnected branches
inclusion bodies.ijm is a macro in ImageJ to analyze size and features of muLEC internal microsomes/inclusions.

See Goble et al. Methods for more details
